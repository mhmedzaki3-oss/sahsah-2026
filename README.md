## النشر على GitHub Pages
1. أنشئ مستودعا Public وارفع محتويات هذا المجلد (index.html, legal.html, manifest.webmanifest, sw.js, icons/).
2. Settings ثم Pages ثم Branch: main / root.
3. افتح الرابط من Chrome على الموبايل ثم «ثبّت التطبيق».

## إصدار كود تفعيل (مالك التطبيق فقط)
بعد استلام تحويل انستاباي ورقم جهاز العميل:
`python make_code.py رقم_الجهاز 30` ثم أرسل الكود للعميل.
مجلد OWNER-ONLY ومفتاح private.pem **لا يُرفعان على GitHub أبدا**.
